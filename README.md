# Customer Shopping Behavior Analysis

## Project Overview
This project analyzes customer shopping behavior to identify purchasing patterns, customer preferences, product performance, and revenue trends.

The project follows an end-to-end data analytics workflow using Python for data cleaning and preprocessing, MySQL for data analysis, and Power BI for interactive dashboard development.

## Dataset Information
- Total Records: 3,900
- Original Columns: 18
- Dataset Type: Customer Shopping Behavior
- Data Format: CSV

## Tools & Technologies
- **Python:** Pandas, NumPy, Data Cleaning, Data Preprocessing
- **MySQL:** SQL Queries, Joins, CTEs, Subqueries, Aggregate Functions, Window Functions
- **Power BI:** Dashboard Development, KPIs, Data Visualization
- **Jupyter Notebook:** Python Analysis
- **GitHub:** Project Documentation

## Project Workflow

### 1. Data Loading & Cleaning (Python)
- Imported the CSV dataset using Pandas.
- Performed initial data exploration using info(), describe(), and head().
- Checked missing values and duplicate records.
- Handled missing review ratings using the median rating of each product category.
- Standardized column names for better readability.
- Created customer age groups using quartiles.
- Converted purchase frequency into days.
- Removed the unnecessary Promo Code Used column.

### 2. SQL Data Analysis (MySQL)
Performed 10 business analysis queries to extract meaningful insights:

1. Revenue Analysis – Compared total revenue generated by male and female customers.
2. Discount & Spending Analysis – Identified discount users spending above or equal to average purchase amount.
3. Product Rating Analysis – Found the top 5 products based on average review ratings.
4. Shipping Analysis – Compared average purchase amounts for Standard and Express shipping.
5. Subscription Analysis – Compared customer count, average spending, and total revenue between subscribers and non-subscribers.
6. Discount Dependency Analysis – Identified the top 5 products with the highest discount rates.
7. Customer Segmentation – Classified customers into New, Returning, and Loyal segments.
8. Product Popularity Analysis – Identified the top 3 most purchased products within each category using ROW_NUMBER().
9. Repeat Buyer Analysis – Analyzed subscription status among customers with more than 5 previous purchases.
10. Age Group Revenue Analysis – Compared total revenue across different customer age groups.

### 3. Power BI Dashboard
Developed an interactive Power BI dashboard to visualize customer shopping behavior and business performance.

The dashboard helps analyze:
- Customer purchasing patterns
- Revenue trends
- Product performance
- Customer segmentation
- Subscription behavior
- Discount and shipping patterns
